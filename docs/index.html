Application information

postiztestLocal integration testing

基于自托管 Postiz 的本地测试应用，用于验证账号授权、素材管理、内容排期及 TikTok 官方发布接口的集成。

当前状态：应用处于有限测试阶段。Postiz 在运营者的本地设备运行，尚未接通 TikTok；本网站仅提供应用说明与政策，不提供账号登录、素材上传或发布功能。

postiztest is a limited local integration test application based on self-hosted Postiz. It is intended to test account authorization, media management, scheduling and TikTok's official publishing APIs. TikTok integration is not yet connected. This public website provides application information and policies only; it does not host the application or accept sign-ins, media uploads or publishing requests.
